# Round 1 design brief

User task: “现在开始做第三阶段”. Apply the agreed three-round offline search to the shared simulator. Using the bounded decision-table interface in the protocol, propose three understandable, structurally different upstream speed-ceiling rules for vehicle 30. Score total travel, follower variation, low-speed time and the last exit with the frozen phase 2 evaluator; all 60 must finish and sampled net gaps must reach at least 2 m. Use only the development split. The existing hand rule achieved mean reward 0.557: follower variation fell 1.43–1.79%, but every exit time was unchanged. On seed 1 it released at 4308 m while the forward speed mean was only 1.59 m/s. Explore what happens if control persists near the queue, and include a less abrupt intervention. Return three complete tables before receiving any new scores.
